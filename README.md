# K예술영재 프로젝트 운영 Hub

2026 K예술영재 프로젝트의 사이트·관리자 페이지·워크숍 자료·평가회의 자료·운영 페이지 링크를 한 곳에 모은 페이지입니다.

- 주소: https://kartsproject.github.io/links/
- 링크를 고치려면 `index.html` 아래쪽 `<script>` 안의 `SITES` · `WORKSHOP` · `MEETINGS` · `OPS` 목록과 맨 위 바로가기 `QUICK` 목록만 수정하면 됩니다.
- 워크숍·평가회의 자료는 「K예술영재 프로젝트 워크샵 아카이브」 시트 내용(2026.11.4 기준)을 옮긴 것이라, 시트가 바뀌어도 자동으로 반영되지 않습니다.
- 관리자 주소가 담겨 있으니 운영진 안에서만 공유해 주세요.
- 「관련 계정」 탭의 계정 정보는 허브 암호로 암호화(AES-GCM, PBKDF2)되어 `VAULT` 값에만 들어 있습니다. 내용이나 허브 암호를 바꾸려면 다시 암호화해야 하므로 파일을 직접 고치지 마세요.
